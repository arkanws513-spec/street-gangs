# Street Gangs — Phaser Edition

نسخة إعادة بناء اللعبة باستخدام Phaser 4، منفصلة عن النسخة HTML الحالية أثناء التطوير.

## المرحلة الأولى
- محرك Phaser 4
- عالم قابل للتمرير بسلاسة
- كاميرا تتبع اللاعب
- مدينة Top-down قابلة للتوسع
- نقاط تفاعل للمقر والتدريب والسوق والمطار والحلبة
- بنية Scenes وsystems قابلة للتطوير

الهدف هو نقل اللعبة من واجهة HTML إلى بنية لعبة حقيقية بدل الاستمرار في ترقيع index.html.
