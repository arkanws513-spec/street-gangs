# Street Gangs — Unity 6

This directory is the new Unity/C# game foundation. The legacy browser client is no longer the target runtime.

## Architecture
- Unity 6 LTS client
- C# gameplay/domain code
- Supabase for persistent online player data
- Server-authoritative validation for economy, XP, missions and training
- City/management UI rather than free-roaming map navigation

## First playable systems
- Player profile and progression
- Cities and travel
- Missions and turn-based abstract battles
- Training: strength, speed, defense, accuracy
- Shop/inventory/trading foundation
- Hospital/prison status foundation
