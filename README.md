# Street Gangs

تجربة لعبة متصفح مبنية باستخدام Next.js وReact وTypeScript.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## فحص إصدار الإنتاج
```bash
npm run build
```

يستخدم المشروع حفظًا محليًا في المتصفح للنسخة التجريبية. لا تعتبر بيانات التقدم المحلية نظام حسابات أو مزامنة بين الأجهزة.
